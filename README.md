# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year Ph.D. candidate at the HKUST NLP Group.

The site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and contains:

- **About** — personal details, education, research experience, publications, research interests and skills, awards, and contact information.
- **Publications** — list of publications, including first-author papers and co-authored papers.
